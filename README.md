# OpenTerm
This is a simple Mac App written in Swift 5 (universal binary: native on Apple Silicon and Intel, macOS 12+) that adds a button to open a terminal in any Finder window.

## Setup
1. Copy `OpenTerm.app` to `/Applications`.
2. Hold ⌘ (Command) and drag `OpenTerm.app` onto the toolbar of any Finder window.
3. Click the OpenTerm button to open Terminal in that window's folder. The first time, macOS asks whether OpenTerm may control Finder; click **OK**.

Right-clicking in Finder also offers **Open Terminal Here**.
